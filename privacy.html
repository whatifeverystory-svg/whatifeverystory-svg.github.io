What If Privacy Policy

Effective 26 October 2026 · What If home

The What If app is a private tool used by the owner of the What If YouTube channel to manage that one channel. It is not a public service: it is used only by the channel owner, on the owner's own computer.

What the app accesses

When the channel owner signs in with Google and allows access, the app uses two Google permissions, and only for the What If channel:

  • YouTube (youtube.force-ssl): to read the channel's own videos and, only after the owner approves each specific change, to update those videos' details: title, description, tags, category, privacy status and publish schedule.
  • YouTube Analytics (yt-analytics.readonly): to read the channel's own performance reports, such as views and watch time.

The app refuses to make changes to any channel other than What If, and it makes no change without the owner's explicit approval.

What the app does not do

  • It does not access other people's accounts or channels.
  • It does not share, sell, rent or transfer any data to anyone.
  • It does not use the data for advertising, and it does not use it to train AI or machine-learning models.
  • It does not upload, delete or comment on videos.

Where data is kept

The sign-in token is stored only on the channel owner's computer, in a private folder readable by that user alone. Analytics figures the app reads are kept in the owner's own project notes for planning. Nothing is stored on any server run by the app.

Google API Services User Data Policy

The What If app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also follows the YouTube Terms of Service; see the Google Privacy Policy for how Google handles data.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked, the stored token stops working, and the owner deletes it from the computer.
